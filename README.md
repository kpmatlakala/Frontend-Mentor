# Frontend Mentor Portfolio

This repository is my Frontend Mentor workspace and portfolio.

It documents my progression from traditional HTML + CSS + JavaScript work into a modern React-based portfolio and application workflow.

## About This Repo

- Purpose: build, ship, and track Frontend Mentor challenge implementations.
- Current transition: migrating portfolio experience from static implementation in the [_/](./_/) folder into the React app in [src/](./src/).
- Important: challenge folders are kept as-is because they are already published/submitted.

## What This Portfolio Shows

- Fundamentals: semantic HTML, accessible forms, visual hierarchy, layout systems.
- Responsive design: mobile-first behavior, breakpoints, fluid spacing and typography.
- JavaScript interaction: validation, state-based UI, accordions, dynamic behavior.
- React progression: component architecture, reusable UI, and maintainable frontend patterns.

## Local Development

From the repository root:

1. Install dependencies
   - npm install
2. Start development server
   - npm run dev
3. Build production bundle
   - npm run build
4. Preview production build
   - npm run preview
